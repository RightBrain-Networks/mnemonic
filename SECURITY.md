# Reporting a vulnerability

Please report suspected vulnerabilities privately. Do not post credentials,
transcript contents, private artifacts, database dumps, or exploit details in a
public issue or pull request.

Use the repository's [private vulnerability reporting form](https://github.com/RightBrain-Networks/mnemonic/security/advisories/new)
when it is available. If GitHub does not offer the form, open an issue asking for
a private reporting channel, without describing the vulnerability. Wait for the
maintainer to establish that channel before sharing sensitive details.

Include the application and plugin versions, deployment method, affected
component, impact, and minimal reproduction steps. Remove secrets and private
content from any logs or examples. The maintainer will coordinate investigation,
fixes, and disclosure with the reporter through the private channel.

For ordinary bugs and installation problems, use the public
[issue tracker](https://github.com/RightBrain-Networks/mnemonic/issues).
