# Optional independent review preference

Read `help(topic="claim_work usage")` and the review command help before loading
work context. Follow the assigned mode's context restrictions and the selected
project's current policy.

Within that permitted scope, examine the behavior the change promises, exercise
important failure paths, and support actionable findings with concrete evidence.
Distinguish observed defects from unresolved questions. Recheck a suspected
finding against the relevant code before reporting it. Prefer a focused review
to a list of speculative improvements. The owner may adopt this methodology;
review eligibility, findings freeze, and closeout requirements remain in help.
