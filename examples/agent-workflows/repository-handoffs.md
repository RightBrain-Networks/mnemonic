# Optional repository handoff preference

When handing off repository-dependent work, record the commit and files actually
inspected, useful verification results, and remaining uncertainty. Read
`help(topic="add_checkpoint usage")` for the current context contract. When
available, the local `mnemonic-recall` repository helper can compare an inspected
baseline and declared paths without changing the repository; treat its result as
evidence with limits.

Use current project settings and command help for claims and closeout. A new
session should inspect changed evidence before relying on a handoff. The owner
chooses when this additional repository comparison is useful.
