# Optional decision documentation preference

For an authorized design decision worth retaining, consult current project
settings and `help(topic="decision_put usage")`. Describe the choice, relevant
alternatives, and evidence concisely. Use the selected domain's conventions. Read
impact help before revising a decision and inspect the returned coverage.

When implementation uses a decision, cite the actual consulted revision and
record actual repository scope using the relevant command help. Keep open
questions explicit. This preference does not authorize resolving a human gate,
changing accepted decisions, or beginning implementation.
